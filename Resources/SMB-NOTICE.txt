Includes libsmb2. See the included LGPL 2.1 license and complete source archive
for copyright notices and component licensing. No library source modifications.

The library is linked as Contents/Frameworks/libAMSMB2.dylib. It can be replaced
with a compatible rebuilt version; re-sign the library and app ad hoc after
replacement. Reverse engineering for debugging modifications to this library is
permitted. No warranty is provided by the library authors.

Build the included source using SwiftPM (swift build --product AMSMB2) with the
Swift toolchain on macOS. The source archive includes both versioned manifests.
